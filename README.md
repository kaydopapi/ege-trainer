# 🎓 ЕГЭ Грамотность — Онлайн-тренажёр (Банк ФИПИ + Школково)

Полноценное интерактивное веб-приложение для подготовки к тестовой части ЕГЭ по русскому языку (задания №4–21). 
Создано на основе официальных кодификаторов и словников ФИПИ и методических материалов онлайн-школы «Школково».

---

## 🚀 Возможности приложения

### 1. Три полных блока заданий
* **🗣️ Нормы языка и грамотность (№4–8):**
  * **№4 Ударения:** Блиц-карточки с кликом по ударной гласной + экзаменационный формат со множественным выбором.
  * **№5 Паронимы:** Поиск ошибки в предложении и ввод верного паронима + каталог значений пар ФИПИ.
  * **№6 Лексика:** Интерактивное исключение лишнего слова (плеоназма) кликом по тексту + замена сочетаний.
  * **№7 Морфология:** Исправление неверной формы слова + справочник трудных случаев (родительный падеж, -А/-Я vs -Ы/-И, повелительные глаголы, числительные).
  * **№8 Синтаксис:** Интерактивная таблица соответствия 5 типов грамматических ошибок и 9 предложений.
* **✍️ Орфография (№9–15):**
  * **№9 Корни:** чередующиеся, проверяемые и словарные корни (поиск рядов с одинаковой буквой).
  * **№10 Приставки:** ПРЕ/ПРИ, З/С, И/Ы, разделительные Ъ и Ь.
  * **№11 Суффиксы:** глаголы (-ова-/-ыва-), прилагательные (-чив-/-лив-, -ев-/-ив-), существительные.
  * **№12 Окончания и причастия:** I и II спряжения, причастия прошедшего времени.
  * **№13 НЕ и НИ:** слитное и раздельное написание со всеми частями речи.
  * **№14 Слитно/дефисно/раздельно:** производные предлоги, союзы, наречия.
  * **№15 Н и НН:** отглагольные и отыменные слова, краткие формы, исключения.
* **📍 Пунктуация (№16–21):**
  * **№16 ССП и однородные члены:** поиск предложений с одной запятой.
  * **№17 Обособленные члены:** причастные и деепричастные обороты.
  * **№18 Вводные слова и обращения.**
  * **№19 СПП:** придаточные предложения с союзными словами.
  * **№20 Стык союзов:** сложные предложения с правилом ТО/ТАК/НО.
  * **№21 Пунктуационный анализ:** поиск предложений с тире, двоеточием или запятой по одному правилу.

### 2. Экзаменационный режим «Пробный вариант»
* ⏱️ Таймер реального времени (30 минут).
* Удобная панель навигации по номерам заданий.
* Автоматическая проверка, подсчёт баллов и подробный разбор ошибок.

### 3. Тетрадь «Работа над ошибками»
* Любое задание с неверным ответом автоматически сохраняется в `localStorage`.
* Режим повторения позволяет тренировать только те вопросы, в которых были допущены ошибки, пока они не будут усвоены на 100%.

### 4. 🔍 Поиск по Словникам ФИПИ (⌘K / Ctrl+K)
* Мгновенный поиск по всей базе слов (ударения, пары паронимов, корни, плеоназмы, исключения).

### 5. Геймификация и звук
* Web Audio синтезатор (звуковые эффекты успеха/ошибки/клика без внешних аудиофайлов).
* Начисление опыта (XP), уровни и звания (от «Новичка» до «Стобалльника ЕГЭ 🏆»).
* Счётчик серий правильных ответов (Streak 🔥).

## 🛠 Технологический стек
* **Frontend:** React 19, Tailwind CSS v4, Lucide Icons, Canvas Confetti.
* **Сборка:** Vite 8.
* **Синтез аудио:** Web Audio API (чистые синусоидальные и треугольные осцилляторы).
* **Хранилище:** LocalStorage (прогресс, статистика, тетрадь ошибок).
